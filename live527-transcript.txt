== 1. Latest stable daemon (v0.25.0) owns the store; the patched CLI explains the upgrade

$ wacli-0.25.0 --store STORE sync --follow   # running

$ wacli-527 --store STORE profile picture-info --jid PEER
the running sync process does not support profile picture-info; restart `wacli sync` after upgrading, then run this again: unsupported send kind "profile_picture_info"

$ wacli-0.25.0 --store STORE profile picture-info --jid PEER   # the stock CLI, for comparison
store is locked (another wacli is running?): store locked: resource temporarily unavailable (pid=2745342 acquired_at=REDACTEDT14:02:01.REDACTED:00)
